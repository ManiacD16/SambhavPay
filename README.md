# SambhavPay — Premium Payment Infrastructure Website

Production-ready React landing page for a modern fintech payment infrastructure brand.

Website: https://sambhavpay-eta.vercel.app/

## What was upgraded

- Light-only premium fintech UI direction
- Deep thermal orange, lava red, earth blue, dark navy, and neutral brand palette
- Responsive navbar, drawer, cards, grids, pricing, docs, contact, and footer
- Subtle reveal-on-scroll, thermal glow, hover, and interaction states
- SEO, AEO, GEO, LLM, and social sharing metadata
- Organization, LocalBusiness, WebSite, Breadcrumb, and FAQ JSON-LD
- `robots.txt`, `sitemap.xml`, `llms.txt`, `ai-discovery.json`, PWA manifest, favicon, app icons, and Open Graph image
- Accessible labels, skip link, semantic sections, improved focus behavior, and reduced-motion support
- Domain references updated to https://sambhavpay-eta.vercel.app/

## Available scripts

```bash
npm install
npm start
npm run build
```

## Deployment

Build the production bundle:

```bash
npm run build
```

Deploy the generated `build/` directory to Netlify or any static hosting provider.
